# minga-youtube

**Одиннадцать навыков Claude для длинных видео на YouTube, на русском и английском: голос канала, сценарий с таймингом по разделам, название и превью как единая пара, монтажный лист по транскрипту, главы, которые действительно отображаются, правильное чтение удержания, SEO, комментарии, планы, исследование и аудит, который заканчивается одним исправлением.**

Часть экосистемы [Minga](https://github.com/dmminga1983/minga). Пара к [minga-reels](https://github.com/dmminga1983/minga-reels) для длинного формата: те же формулы хуков, тот же движок русского и английского текста, а Shorts, нарезанные из длинного видео, уходят в `/reels-repurpose`. Бесплатно, MIT, без API-ключей, ничего подключать не нужно. **За вас ничего не загружается:** каждый навык заканчивается готовым блоком и вопросом «выпускаем или правим?».

## Одиннадцать навыков

| команда | что делает |
| --- | --- |
| `/yt-channel` | Файл канала, который читают все навыки: один зритель, обещание, как говорит ведущий, формат. |
| `/yt-script` | Пять хуков по 26 формулам с оценкой; переход к сути до 0:45; биты с тем, что на экране; тайминг через `outline.py`. |
| `/yt-package` | Название и превью как одно целое, с проверкой `title.py`: обрезка на мобильном, конкретика, эмоции, капс, повторы. |
| `/yt-edit` | Монтажный лист по транскрипту: паузы, слова-паразиты, повторные дубли, с таймкодами и CSV. |
| `/yt-chapters` | Главы по транскрипту, проверенные по правилам YouTube, чтобы они отображались. |
| `/yt-retention` | Выгрузка удержания из Studio: потери на старте, обрывы с тем, что говорилось в этот момент, плавный спад, и одно изменение. |
| `/yt-seo` | Описание, теги и проверка запросов: есть ли слова поисковых запросов в названии и первых двух строках? |
| `/yt-comment` | Сортировка комментариев, ответы голосом канала, какой комментарий закрепить. |
| `/yt-plan` | Неделя под реальные часы: одно главное видео, одно дешёвое, Shorts из главного. |
| `/yt-viral` | Что работает в нише, по кратности к медиане своего же канала, с формулой названия. |
| `/yt-audit` | Весь канал, а в итоге ОДНО исправление вместо двадцати. |

## Установка

**Claude Code**, как плагин:

```
/plugin marketplace add dmminga1983/minga-youtube
/plugin install minga-youtube@minga-youtube
```

Или скопируйте папки, чтобы команды назывались просто `/yt-script` и так далее:

```bash
git clone https://github.com/dmminga1983/minga-youtube.git
cp -r minga-youtube/skills/yt-* ~/.claude/skills/
```

**claude.ai**: заархивируйте папку одного навыка и загрузите её в Настройки, Возможности, Навыки.

Инструментам нужен Python 3.8 или новее, больше ничего. Начните с `/yt-channel` или пришлите Claude три своих видео со словами «напиши файл канала по этим».

## Инструменты

Чистый Python без зависимостей, без сети, никуда ничего не загружается.

```bash
python3 skills/yt-script/hookscore.py hooks.txt                 # оценка хука, 26 формул
python3 skills/yt-script/outline.py script.md --pace 4.8         # тайминг по разделам
python3 skills/yt-package/title.py --title "..." --thumb "..."   # пара название и превью
python3 skills/yt-edit/deadair.py transcript.srt --csv cuts.csv  # монтажный лист
python3 skills/yt-chapters/chapters.py transcript.srt --target 8 # корректные главы
python3 skills/yt-chapters/chapters.py --check chapters.txt
python3 skills/yt-retention/retention.py retention.csv --duration 612 --transcript t.srt
python3 skills/yt-seo/seo.py --title "..." --queries "запрос1,запрос2" --tags "тег1,тег2" desc.txt
python3 skills/yt-viral/swipe.py collected.tsv --min 2
```

Транскрипт подойдёт в формате SubRip, WebVTT, JSON от Whisper или json3-субтитры YouTube. Чтение удержания понимает выгрузки Studio с русскими или английскими названиями столбцов, а позицию в секундах, в мм:сс или в долях видео.

```bash
python3 -m unittest discover -s tests -v
```

## Важные оговорки

- **Навыки ничего не загружают.** API YouTube это позволило бы с вашей собственной авторизацией, но здесь это намеренно не сделано. Публикуете вы.
- **Оценка хука это эвристика.** Она хорошо ловит слабое начало, но не выберет победителя из двух хороших. `calibrate.py` из minga-reels измеряет её на ваших собственных видео.
- **Формула названия описывает слова, а не причину.** Когда `/yt-viral` называет формулу, это про видимое название, а не про то, почему видео набрало просмотры.
- **Исследование читает, а не парсит.** Публичные списки через `yt-dlp` на вашем компьютере, без входа в аккаунт.
- **Теги почти ничего не решают**, и навык прямо так и говорит, вместо того чтобы продавать генератор тегов.
- **Ничего не выдумывается.** Недостающую цифру навык спросит или оставит `{{your number}}`.
- **Цифры площадки меняются.** Лимиты здесь проверены в октябре 2026 года. Если YouTube говорит иначе, прав YouTube.
