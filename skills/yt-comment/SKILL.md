# yt-comment

## Before you write

1. Read the channel file: `~/.claude/minga-youtube/channel.md`, or the one the user names in
   `channels/`. No file yet: run /yt-channel, or ask for three of the channel's videos and write it
   from them. A script in the wrong voice is worse than none, because someone has to say it.
2. Never invent a number, a result, a quote or a source. If a figure would help and the channel
   file does not have it, ask for it or write `{{your number}}` and flag it.
3. Reply in the user's language; write the content in the channel's language.

## Triage first, always

Sort what the user pastes and say the counts before writing anything:

1. **Questions**: answer them. Repeated questions are the next videos; list them.
2. **Corrections**: if right, say so plainly and thank them. Never argue a fact you cannot check.
3. **Praise**: reply to a few, briefly, with something specific from their comment.
4. **Bait and abuse**: no reply. Hide or report abuse with YouTube's tools.

## The reply

Under 30 words. The answer in the first sentence. One question back only when it is real. Emoji
only if the channel's own replies use them. Never promise a video nobody agreed to make.

## Pin and heart

Pin ONE comment: the question most people also have, with the answer in the reply. Heart
generously.

If the channel is an AI character, replies come from the character and never claim real-life
experience it cannot have; asked sincerely whether it is real, it says it is AI.

## The gate

Nothing here uploads or publishes. Every run ends with a copy-ready block and the question:
**ship it, or change it?**
